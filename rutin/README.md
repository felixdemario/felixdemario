# Haftalık Rutin

Her gün yapılacak rutinleri hafta hafta işaretlemek için iPhone'a eklenebilen web uygulaması.

- Pazartesi–Pazar haftalık ızgara; kutuya dokun, işaretle.
- "Her gün" ya da "Haftada N gün" hedefi (örn. Spor: haftada 4 gün).
- Ana ekrana eklenince tam ekran açılır, internetsiz çalışır.
- Veriler yalnızca telefonda (tarayıcı depolaması) tutulur.

Adres: https://felixdemario.github.io/felixdemario/rutin/
